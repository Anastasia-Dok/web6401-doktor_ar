# Лабораторная работа №3

## Цель
Изучение основ JavaScript.

## Что сделано
Реализованы функции в файле `lab3/src/core.js` согласно заданию:

- **`isInteger(n)`** — проверяет, является ли число целым, используя побитовые операторы.
- **`even()`** — возвращает массив чётных чисел от 2 до 20 включительно.
- **`sumTo(n)`** — считает сумму чисел до `n` с помощью цикла.
- **`recSumTo(n)`** — считает сумму чисел до `n` с помощью рекурсии.
- **`factorial(n)`** — вычисляет факториал числа `n`.
- **`isBinary(n)`** — определяет, является ли число степенью двойки.
- **`fibonacci(n)`** — находит N-е число Фибоначчи.
- **`getOperationFn(initialValue, operatorFn)`** — возвращает функцию, выполняющую операцию над накопленным значением.
- **`sequence(start, step)`** — создаёт генератор арифметической последовательности.
- **`deepEqual(firstObject, secondObject)`** — рекурсивно сравнивает два объекта по содержимому.
