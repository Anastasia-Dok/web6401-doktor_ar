# Лабораторная работа №2

## Тема сайта
Многостраничный сайт про рецепты «Вкусно и просто».

## Структура проекта
- `lab2/index.html` — главная страница
- `lab2/recipes.html` — каталог рецептов 
- `lab2/recipe.html` — подробный рецепт 
- `lab2/products.html` — всё о продуктах 
- `lab2/css/style.css` — стили

## Что использовано
### HTML
- Блочные элементы: `<header>`, `<nav>`, `<div>`, `<p>`, `<ul>`, `<ol>`, `<table>`
- Строчные элементы: `<span>`, `<a>`, `<strong>`
- Ссылки — навигация между страницами
- Изображения — на каждой странице
- Таблица — на `recipes.html` и `products.html` с разным выравниванием

### CSS
- Отдельный файл `css/style.css`
- Селекторы: тега, класса, id, потомка, псевдокласса (`:hover`)
- Цвета: HEX (`#8b2e2e`, `#f5b342`)
- Выравнивание в таблице: влево / по центру / вправо
